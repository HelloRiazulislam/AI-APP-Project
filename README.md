# AI App Project

Node.js project for an AI app. Author: Riazul Islam.

## Stack

- Node.js
- TypeScript (planned for new files)
- [dotenv](https://www.npmjs.com/package/dotenv) for environment variables

## Setup

```bash
npm install
```

Create a `.env` file in the project root for secrets and config (do not commit it).

## Scripts

```bash
npm test
```

No app entry or tests are wired up yet. Add start/dev scripts when you add `index.js` or TypeScript source.
